# 🛠️ SKILL: VISUAL QC INSPECTOR & SCREENSHOT HARNESS
*Diadaptasi untuk tool Flowork:* `screenshot` | *Referensi:* ECC Browser QA Visual Regression & Screen Capture

Prosedur Operasi Standar (SOP) resmi kedaulatan Flowork OS untuk inspeksi visual GUI dan desktop.

## 1. DOKTRIN SCREENSHOT MANDATORI
- **Korteks Penglihatan Nyata**: Tangkapan layar yang diambil via screenshot langsung diperiksa secara detail (layout, overflow, warna kontras).
- **Haram Halusinasi Visual**: Pantang mengklaim tampilan web/plugin telah rapi tanpa memverifikasi bukti screenshot fisik.
- **Tampilkan ke Obrolan**: Lampirkan tangkapan layar penting untuk transparansi dengan Super Admin.
