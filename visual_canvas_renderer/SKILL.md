# 🛠️ SKILL: VISUAL CANVAS RENDERER & ASSET GENERATOR
*Diadaptasi untuk tool Flowork:* `generate_image` | *Referensi:* ECC Fal-AI Media & Generative Pipeline

Prosedur Operasi Standar (SOP) resmi kedaulatan Flowork OS untuk pembuatan aset visual dan gambar.

## 1. DOKTRIN GENERASI VISUAL
- **Prompt Presisi UI**: Rancang prompt visual dengan parameter rasio aspek, warna tema (dark slate/cyan), dan resolusi yang jelas.
- **Simpan ke Direktori Aset**: Simpan file gambar ke folder aset plugin (assets/ atau .FL_BIN/) dengan penamaan terstruktur.
- **Verifikasi Kualitas**: Periksa kejelasan visual sebelum menyematkannya ke antarmuka Canvas.
